# Agent instructions

This file tells agents working in this repo where the engineering skills keep
their configuration. The project constitution is `README.md`; the migration
plan is `document/handoff.md`; adjudicated decisions are
`document/adjudication.md`.

## Agent skills

### Issue tracker

Work is tracked in `document/adjudication.md` (decision/issues log) plus
`document/handoff.md` (progress) — no separate tracking system. See
`docs/agents/issue-tracker.md`.

### Domain docs

Single-context: glossary at `document/context.md`, ADRs under
`document/adr/`. See `docs/agents/domain.md`.
